📚 How to Use These Documents

  • For New Team Members: Start with Brand Overview → then read Messaging + Communication guides
  • For Marketing Teams: Use Messaging for campaigns, Communication for execution, Overview for strategy alignment
  • For Sales Teams: Focus on Messaging (value props, competitive positioning), use Communication for presentations
  • For Leadership: Review Complete Strategy annually, use Overview for stakeholder communication
  • For Partners/Agencies: Share Overview + Messaging + Communication for brand understanding
